⚠ The portal error “Predicted values must be in range [0, 1]” — fixed

DrivenData rejects if values outside [0,1] OR nodata sentinel outside [0,1]. Two mechanisms measured on this competition's own data:

  • Mechanism 1 — float32 sentinel: training_features.tif uses -3.4028234663852886e+38 as nodata: 7,113,308 cells, 3,061 inside footprint. Writing through unchanged puts them outside [0,1].
  • Mechanism 2 — NaN inside footprint: Feature raster valid mask 5,165,852 vs template 5,167,373 → 3,061 scored pixels as NaN if mask derived from feature band.

Fix (verified by re-reading bytes): footprint only from np.isfinite(sample_submission.tif), map NaN→0, +Inf→1, -Inf→0, clip to [0,1], write zero outside, then re-read and assert all 12,279,160 finite and in range before exit 0. This file: all-finite, nodata=None, min 0 max 1, 0 NaN, 0 Inf.

Is zero-outside legal? Yes: reference solution writes no nodata and finite sigmoid everywhere; owner ledger shows r7-nms3-dem10-scarp_0c9199f14e62=0.1294 and …_allfinite=0.1294 identical — outside cells carry no scoring weight. NaN-outside twin also provided.

Three facts from metric arithmetic

  1. Metric is budget: DTI = TPw / (0.2*(TPw+FPw) + 0.8*|G|). Every emitted pixel costs 0.2, earns at most 1. Hidden truth |G|≈12.6k px (0.24% of cells) from blind lattice 0.0904.

MINE — Mutual Information Filter (Not Noisy Ablation)

With faults covering ~1% area, holdout ablation — add feature, rerun, see if DTI moves — runs on so few positives that delta is noisy, easily mistaken for signal or nothing. MI directly measures how much feature's value reduces uncertainty about true label, independent of whether any particular model exploits relationship well.

Belghazi et al., MINE (ICML 2018) makes this computable for high-dimensional continuous features: https://arxiv.org/abs/1801.04062

Compute MINE-estimated MI between each candidate feature and true label on full label set, not only small ablation holdout, and use as far-less-noisy first-pass filter — feature with near-zero MI unlikely to earn back submission slot no matter how model tuned.
